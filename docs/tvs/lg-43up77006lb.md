# LG 43UP77006LB

webOS 6.0 (2021), 4K, Magic Remote. TV Thuis is hier een LG-app. Het LG-startscherm blijft staan. Een cijfertoets die je zelf kiest, opent TV Thuis. LG-apps, loggers en reclamekanalen blijven aan: webOS heeft geen Android-pakketten om uit te zetten.

webOS 6 laat een app uit de ontwikkelaarsmodus niet zelf de geïnstalleerde apps zien. Na de eerste start vraagt de tv één keer om de toegang die de LG-telefoonapp ook gebruikt. Sta die toe, anders blijft de app-plank leeg of onvolledig.

## Op de tv

1. LG Content Store → installeer **Developer Mode**.
2. Log in met een gratis LG-ontwikkelaarsaccount.
3. Zet **Dev Mode Status** aan. De tv herstart.
4. Zet **Key Server** aan.
5. Noteer het IP-adres en de passphrase op dat scherm.

Developer Mode vervalt na ongeveer 40 dagen. Open de Developer Mode-app af en toe en druk op **EXTEND**.

## Op de computer

Python 3. Zelfde wifi als de tv.

```bash
python3 webos/build.py
python3 webos/install.py <ip-van-de-tv>
```

De eerste keer vraagt het script om de passphrase. Een update daarna niet.

Verwijderen:

```bash
python3 webos/install.py <ip-van-de-tv> --uninstall
```

## Op de tv, daarna

1. Open **TV Thuis** uit de app-lijst.
2. Houd een cijfertoets op de Magic Remote ingedrukt terwijl de app open is. Die toets opent hem daarna vanaf elk scherm.
3. Als de tv om app-toegang vraagt: toestaan, en de app één keer sluiten en opnieuw openen. Dan komen Netflix, YouTube en de rest op de plank, met pictogrammen.
4. Home Settings → **AIO Media**: server (het adres van jullie manager), gebruikersnaam, wachtwoord, Verbinding testen.
5. Home Settings → **Stad**.
6. Installeer Jellyfin of Plex uit de Content Store als je vanuit Nieuw toegevoegd wilt openen.

De schermbeveiliging van TV Thuis komt na een paar minuten nietsdoen, zolang de app op de voorgrond is: trendingposters op zwart, met klok en weer.
